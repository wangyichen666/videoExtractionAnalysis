# 财经专家 v2

## 输出与复用

财经预设finance-v2输出六章：核心主题、账户与市场表现、标的观点、政策与行业逻辑、风险与历史教训、关键结论。公司/资产分三级标题，保留数字口径、依据、操作、前提与不确定性；区分实际持仓和举例。书面文章继续由共享编辑引擎生成，与专家解读独立，保留原文定位、校准记录与双导出。

`expert_profiles.py`保存模板和章节，`finance.py`负责短视频整篇编排，`report_engine.py`复用分片、编辑、缓存、证据校验与长文归纳。`finance_entities.py`保存有限的公司身份参考。阅读组件根据结果章节渲染，无特定BV号、视频标题或固定报告正文分支。

完整带段号材料不超过24000字符时，财经六章基于全部原稿一次输出JSON，避免按类别抽取漏掉账户或财务信息。超过此限时继续逐章归纳，各财经章节读取全体证据笔记以交叉核对。章节数量、顺序、正文长度及所有引用均校验，失败至多修复一次；缓存仅保存通过校验的阶段。

密集引用先全部校验再选择两个代表位置显示，完整引用保存于章节evidence_ids。不能先删掉非法引用再称验证通过。文稿中的数字仍是作者转述，段号有效不证明数字或逻辑准确。

## 财经内容规则

- 区分【视频观点】【专家补充】【待核实】，不把垄断、无缺陷、低估或机构偷跑等观点变成确定事实。
- 股数、金额、币种、股息率和股息支付率分开；账户整合不等于净加仓，也不能据此推断资产集中度上升。不同口径收益率不能擅自加总。
- 政策适用金额、面积、首套条件等按视频转述；没有正式文件不称已核实。解释传导时区分购房融资成本与物业收入。
- 低估值不等于见底，历史抗跌不等于未来收益。不能把破净的低价判断写成企业缺陷。市盈率=市值/净利润，市净率=市值/净资产；股息支付率=分红/利润，股息率=股息/股价。
- 不新增用户行动清单，不生成个性化买卖指令。录制时的行情与观点不等于当前行情建议。

## 兼容与页面

内置默认金融专家升级为财经专家v2；用户修改的名称和提示词保留，不反复升版本。finance-v1仍可读、可生成，历史报告与快照不覆盖。程序员/通用/自定义继续使用原profile和流程。

财经阅读沿用已有工作台设计，正文使用蓝色章节标题、分公司小标题与要点；来源和生成时间可见。公司核对区折叠显示原稿写法、疑似状态及官方链接，专家解读/整理文章可分别下载。页内引用仍可展开原字幕并聚焦具体段落。
