# 设计决策：视频文字工作台

使用已安装的 design-visual-frontend skill。表面类型为 command-led，正文区域为 reading-led。

- Surface：个人知识工作者，把视频链接转换为可阅读的文章及专业解读。
- P1：当前稿件和阅读模式；P2：专家、模型与任务状态；P3：目录、时间引用和校准依据；Action：提取/生成，随后阅读与核对。
- Content truth：现有字幕、实际任务状态、模型输出及校准记录；不使用装饰性假指标。
- Composition：移动端 `[精简导航][可折叠提取栏][稿件+生成工具][解读/文章][正文][校准记录]`；宽屏 `[提取/资料栏 | 稿件及工具条 / 目录 | 阅读正文 | 校准侧栏]`。
- System：低饱和绿色为操作色，深墨色正文、浅灰工具区、白纸阅读区；13px工具/16px正文/24px文章标题；4/8/12/16/24间距；6px控件/10px文档容器；Lucide图标；只给浮层投影。
- Signature：时间定位与校准记录把“文章”连到“视频证据”，常驻目录支持长文阅读。
- Cliche budget：0；无营销hero、装饰仪表或渐变卡片。
- Failure risks：顶部堆叠推迟正文（测首段起点）；超宽屏固定内容留下空白（1920/2560检查目录、正文与证据栏的职责）；移动端提取栏阻塞阅读（折叠后核对390首屏）。

验证矩阵：390x844、768x1024、1440x900、1920x1080、2560x1080。需检查长篇真实模型结果、目录/模式切换、焦点/禁用/错误、减少动态与控制台错误。

复测记录：390px发现目录flex子项引起整体min-content宽度1620px，增加Grid/子项min-width:0与minmax(0,1fr)后页宽恢复390px。1440/1920正文行宽受控，1920加入真实校准侧栏；2560使用2240工作区及920正文行宽，两侧为任务/目录/校准。手机控件与可点击summary最小44px，关闭动态使用prefers-reduced-motion。

## 财经研究笔记扩展

表面仍是工作台中的reading-led研究笔记。P1为核心主题与分公司观点，P2为账户、市场和政策逻辑，P3为时间定位和公司身份来源。内容全部来自当前视频、模型解释及带来源的有限身份候选；不使用截图数值填补原字幕缺口。沿用已有操作色和排版，财经章标题增加蓝色强调与细分隔线，公司用三级标题和要点。模式和专家的切换继续共用控件；来源、生成时间与录制时期范围可见，公司核对折叠在正文后。重点复测手机标题/代码换行、六章切换、身份链接、原文定位、文章及程序员模式隔离。

财经最终验收（2026-10-01）：示例记录 a5551a20-6ee8-4788-9947-d8a53a955319，真实 DeepSeek 生成六章解读与两节整理文章。390/768/1440/1920/2560px 页面宽分别等于视口宽，无横向溢出；截图为 artifacts/finance-preview-*.png。正文宽上限1000px，1800px以上将公司名称核对放入280px侧栏，窄屏与文章视图使用底部折叠核对区，避免重复展示。

最终交互：六章切换正常；标的观点展示四组公司/案例；切换程序员模式显示该专家空状态，没有串用财经结果；文章两节目次与独立下载正常，两个导出接口200且包含来源/生成时间；引用展开原稿并聚焦segment-13。最终浏览器console error为空，测试后恢复默认视口。标的截图 finance-holdings-preview.png。

最弱维度仍是390px阅读效率：首屏保留完整操作，正文需要继续滚动。未实测手机原生浏览器和屏幕阅读器。内容最弱项是字幕公司指代、口语数字与归属：例如400股一段紧邻“海基”，生成稿也将其关联航空信息标的，存在过度归属可能；段号合法不等于归属正确，不能把模型结果当已核实财务事实。身份候选字典只核对名称/代码，正式财报、政策与音视频回听尚未逐项验证。
